# 리눅스

학습 기록은 `09-심화-운영/`에 있다. 9장 디스크·보안·성능 명령의 실행 결과와 트러블슈팅이다. 초기 실습 파일도 이 폴더로 옮겨 두었다.

| 경로 | 내용 |
|---|---|
| `scripts/hello.sh` | 첫 스크립트 |
| `scripts/healthcheck.sh` | 상태 점검. 로그는 `logs/health.log` |
| `logs/health.log`, `logs/output.log` | 점검과 `ls` 리다이렉션 로그 |
| `web/index.html` | 간단한 웹 파일 |
| `files/hello.txt`, `backup/` | 초기 실습 파일 |

`09-심화-운영/9-1`의 `du` 출력은 옮기기 전 경로(`~/linux-lab/scripts` 등)를 찍은 기록이다.
